# 🎮 Mini-Games JS: Browser-Based Game Collection

A collection of classic web-based games built using **HTML**, **CSS**, and **JavaScript**. This project showcases the fundamentals of interactive UI design and core game logic implemented directly in the browser without external libraries.

## 🕹️ Games Included

- **Tic Tac Toe**  
  A two-player grid game with real-time win detection and reset functionality.

- **Snake Game**  
  A single-player snake game using `canvas`, featuring keyboard controls, collision detection, and increasing difficulty.

## 🌐 Technologies Used

- HTML5  
- CSS3 (with responsive styling)  
- JavaScript (DOM manipulation, game logic, canvas API)
